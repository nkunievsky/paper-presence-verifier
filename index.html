Verify a paper.

Check that a PDF matches its signed time allocation certificate. Choose each file from your device or paste a direct link.

Registry key

The default key belongs to the registry used by this project. For another registry, choose its public key file from a source you trust independently of the certificate.

Files are checked in your browser.
What does verification establish?

A matching PDF and a valid signature tie the exact document to the registry’s time allocation. Recorded presence is measured in person-time. Estimated engagement is a model output. These checks do not establish an author’s identity or attention.

For links, use the downloadable PDF or certificate. Some repositories serve a cover page, rebuild PDFs, or block browser downloads. You can always select a downloaded file.
